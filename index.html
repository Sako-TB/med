Letter-29 / AP0820 label sheet: US Letter paper, a 3 × 7 grid of 2.831 × 1.57 in labels — 21 per sheet, edge to edge with no margins. The locked version below freezes the grid — exact row heights, fixed column widths, zero cell padding — so placing a label can never resize a cell. Placing labels in Word
  1. Download label PNGs from the Syringe Labels tab — they carry their true print size and come in at exactly 2.83 × 1.57 in.
  2. Click into a cell, then drag the PNG in (or Insert → Pictures), keeping the default “In Line with Text” layout.
  3. If a picture ever shows a wrong size: right-click it → Size → set height 1.57″, width 2.83″.
When printing: set the paper size to US Letter (8.5 × 11 in) — not A4 — and print at 100% scale (“Actual size”), otherwise the labels won’t line up with the die-cut sheet.

When printing: paper size US Letter (8.5 × 11 in) — not A4 — at 100% scale (“Actual size”). The PDF already asks the viewer to default to Actual size — just don’t switch it to “Fit”. The sheet is full-bleed with ink to every edge: if your printer supports borderless printing, enable it; otherwise the outer few millimetres stay unprinted (printer hardware margin) while all label positions still line up exactly. Label content keeps a ≥4.5 mm safe zone from every edge, so a hardware margin can only ever clip background colour — never text, numbers, or the logo.
